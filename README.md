# PPT A4 PDF 去白边工具

## 功能介绍

解决腾讯文档等在线PPT平台下载PPTX/PDF后排版错乱的问题。通过将PPT通过打印导出为PDF，然后使用本工具可以将PDF切割成合适的PPT形态（16:9比例）。

## 解决的问题

- 腾讯文档等在线PPT平台直接下载PPTX/PDF经常出现排版错乱
- 打印导出的PDF会有较大的白边，不适合作为PPT使用

## 使用方法

### 1. 导出PDF

在做PPT的平台（如腾讯文档）：

- 点击「打印」→「另存为PDF」
- 设置：每张打印页数=1，边距=无
- 保存PDF

### 2. 使用工具

1. 用浏览器打开 `index.html`
2. 上传刚才导出的PDF文件
3. 可选：设置输出文件名和底部额外微裁参数
4. 点击「处理并下载」

## 裁剪规则

- **第1页（封面）**：居中裁剪（上下保留白边）
- **第2页起**：贴顶裁剪（只保留底部白边）
- 输出比例：16:9

## 参数说明

- **输出文件名**：裁剪后PDF的文件名（不含.pdf）
- **底部额外微裁**：底部额外裁剪的点数（pt），默认4。若底部仍有极细白缝，可调到6～10

## 技术依赖

- pdf-lib：用于PDF处理（通过CDN加载）

## 浏览器支持

需要支持ES6+和File API的现代浏览器。
